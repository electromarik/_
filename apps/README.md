# MusicX Player — исходники с нуля

Два независимых, написанных с нуля музыкальных плеера (не связаны с
компилированным `MusicX Pro.app`, который раздаётся на сайте в `site/`):

- **`python-player/`** — кросс-платформенный плеер на Python (tkinter + pygame).
  Работает на Windows, macOS и Linux. Проверен запуском в этой среде
  (headless, с синтетическим аудиофайлом) — играет, ставит на паузу,
  переключает треки, регулирует громкость.
- **`swift-player/`** — нативный плеер для macOS на SwiftUI + AVFoundation.
  Написан вручную, **не скомпилирован** (среда без Xcode/macOS) — соберите
  и проверьте в Xcode перед использованием.

Оба — отправная точка, а не замена `MusicX Pro`: простой плейлист,
play/pause/next/prev, громкость, автопереход между треками.
