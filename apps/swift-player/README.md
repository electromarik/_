# MusicX Player (Swift edition)

Нативный музыкальный плеер для macOS на SwiftUI + AVFoundation.

> ⚠️ Этот код написан и не был скомпилирован — в среде, где я его писал, нет
> macOS/Xcode и доступа к SwiftUI/AVFoundation, поэтому проверить сборку я не
> смог. Код написан аккуратно и использует стандартные, хорошо документированные
> API, но перед использованием соберите и проверьте его в Xcode на своей машине.

## Требования

- macOS 12+
- Xcode 14+ (или Swift 5.9+ command line tools)

## Запуск для разработки

```bash
cd swift-player
swift run
```

Откроется окно плеера. Этот способ удобен для разработки, но не создаёт
полноценный `.app`-бандл с иконкой.

## Сборка полноценного .app

1. Откройте `Package.swift` в Xcode (File → Open).
2. Xcode сам распознает пакет; выберите схему `MusicXPlayer` и нажмите ⌘R.
3. Чтобы получить дистрибутив (`.app` / `.dmg`), создайте новый таргет
   "App" в Xcode и перенесите файлы из `Sources/MusicXPlayer` в него —
   так вы получите полноценный бандл с Info.plist и иконкой, который можно
   подписать и упаковать так же, как MusicX Pro.

## Структура

```
Sources/MusicXPlayer/
  MusicXPlayerApp.swift   — точка входа (SwiftUI App)
  ContentView.swift        — интерфейс: плейлист, кнопки управления, громкость
  PlayerViewModel.swift    — логика воспроизведения на AVAudioPlayer
  Track.swift              — модель трека
```

## Возможности

- Плейлист: добавление файлов через системный диалог, удаление выбранного
- Play / Pause / Stop / предыдущий / следующий трек
- Перемотка по слайдеру, автопереход по окончании трека
- Регулировка громкости
