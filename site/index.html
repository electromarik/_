Технологии

Современный full-stack

Backend: Node.js · TypeScript · Express Real-time: Socket.io БД: PostgreSQL · Prisma ORM Frontend: React · Vite · Tailwind CSS Состояние: Zustand · Axios
Быстрый старт

Запуск за 5 минут

  • 1База данных: поднимите PostgreSQL и создайте пользователя/БД.
  • 2Backend: cd server && npm install && npm run prisma:migrate && npm run dev
  • 3Frontend: cd client && npm install && npm run dev
  • 4Откройте localhost:5173, зарегистрируйте пользователей и начните чат.
$ cd server
$ npm install
$ npm run prisma:migrate
$ npm run dev
→ http://localhost:4000

$ cd client
$ npm install
$ npm run dev
→ http://localhost:5173
