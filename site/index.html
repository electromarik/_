Вопросы

Частые вопросы

macOS пишет, что приложение повреждено или от неизвестного разработчика — что делать? ⌄

Это стандартная проверка Gatekeeper для приложений вне App Store. Кликните правой кнопкой по MusicX Pro.app → «Открыть» → подтвердите открытие. Это нужно сделать только один раз.

Подходит ли приложение для Mac на Apple Silicon (M1/M2/M3)? ⌄

Да, оно запустится через Rosetta 2, которую macOS предложит установить автоматически при первом запуске, если её ещё нет.

Нужен ли интернет для работы приложения? ⌄

Нет, после скачивания приложение работает локально на вашем Mac.
